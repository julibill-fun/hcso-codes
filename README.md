# HCSO Codes

Searchable Hillsborough County Sheriff’s Office signal codes, 10-codes, squads, and districts.

**Live app:** https://julibill-fun.github.io/hcso-codes/

Open in Safari (iPhone) → Share → Add to Home Screen.

Public CAD / RadioReference listings — not a live SOP. HCSO covers unincorporated Hillsborough only.
District map: http://gis.hcso.tampa.fl.us/publicgis/boundaries/
